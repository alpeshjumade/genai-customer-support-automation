# SAP Use Cases

This GenAI customer support automation solution can be deployed on SAP BTP to support SAP business users.

## SAP-Relevant Scenarios
- SAP BASIS incident response automation
- Functional user support ticket replies
- Billing and order inquiries linked to SAP S/4HANA
- Integration with SAP systems via APIs and OData services

## Deployment Concept
- GenAI hosted on SAP BTP
- Secure API-based integration with SAP systems
- Reusable prompt templates for enterprise-scale automation
